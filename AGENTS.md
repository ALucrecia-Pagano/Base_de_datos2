# Instrucciones para asistentes de IA — Base de Datos II

Este repositorio reúne dos partes. Antes de trabajar en una de ellas, leer sus instrucciones específicas, que tienen prioridad para esa carpeta:

- [Relacional_PostgreSQL/AGENTS.md](Relacional_PostgreSQL/AGENTS.md) — unidades 1 a 6 (PostgreSQL).
- [NoSQL_y_Movil/AGENTS.md](NoSQL_y_Movil/AGENTS.md) — unidades 7 y 8 (MongoDB y SQLite).

Las rutas que esos archivos mencionan son relativas a su propia carpeta.

## Reglas comunes

- No ejecutar `git add`, `commit`, `push`, `merge`, `rebase`, `reset`, `clean` ni otras operaciones que escriban en Git sin autorización expresa. Amanda realiza los commits.
- No conectarse a motores ni ejecutar SQL, JavaScript o scripts sin autorización para esa etapa y destino. Aprobar un script no autoriza ejecutarlo.
- No modificar TPs ya entregados salvo pedido explícito; registrar las observaciones como mejoras.
- Usar solo datos de prueba o anonimizados. No publicar credenciales, respaldos completos ni datos personales reales.
- Registrar el uso de IA en la bitácora y la DUIA correspondientes.
