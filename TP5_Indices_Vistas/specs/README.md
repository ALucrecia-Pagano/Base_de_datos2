# Especificaciones Kiro de TP5

Las especificaciones se conservan junto a la pieza que describen para mantener
la trazabilidad del trabajo:

- `../Parte_A_Indices/specs/`: tres candidatos de indexado.
- `../Parte_B_Vistas/specs/`: una especificacion por vista y una
	especificacion consolidada de seguridad.
- `../Parte_C_Vista_Materializada/specs/`: reporte materializado.

Los wrappers `../indices.sql` y `../views.sql` son los puntos de entrada
reproducibles exigidos por la entrega.
